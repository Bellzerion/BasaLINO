# Assets Directory

This directory contains visual and data assets used by BasaLINO.

## Structure
- `assets/images/`: Illustration covers and icons.
  - `placeholder_ibalong.png`: Cover placeholder for *Ibalong* story (Suggested ratio: 16:9 or 4:3, recommended 600x400px).
  - `placeholder_mayon.png`: Cover placeholder for *The Legend of Mount Mayon* (Suggested ratio: 16:9 or 4:3, recommended 600x400px).
  - `logo.png`: Application logo.
- `assets/data/`: Static seed files and local data sources.
  - `stories.json`: Seed metadata for stories.
  - `chapters.json`: Multilingual text, paragraphs, and vocabulary hints for chapters.
  - `challenges.json`: Questions and choices for reading checks.
  - `challenge_keys.json`: Private answer keys (strictly for mock testing; in production, stored securely in Firebase).
